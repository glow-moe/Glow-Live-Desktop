# Unreleased (dev)

Changes riding the rolling dev build, waiting for the next numbered release. Add
a line here as you build; at release time this list becomes the release notes
and gets cleared.

- Discord shows what you're reading ahead of the song playing in another tab, the same order as your glow page: watching, then reading, then listening.
- League: the app no longer piles up connections to the League client. After a while in lobby or champ select the client started refusing them, which dropped your Discord status and your L!VE card until the match loaded.
- Steam: the built-in game table refreshed (19662 games) so new releases get their own "Playing <game>" headline offline too.
